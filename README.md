# diplom_project

Дипломный проект — интернет-магазин на Django.

## Возможности

- Каталог товаров с категориями и пагинацией (по 4 на страницу)
- Страница товара: описание, цена, количество, продавец, комментарии
- Корзина («Storage»): добавление, изменение количества, удаление товара, оформление покупки
- Избранное: добавление и удаление товаров
- Поиск по названию товаров с историей поиска для вошедших пользователей
- Регистрация, вход, выход
- Профиль продавца
- Добавление, редактирование и удаление товаров (для продавцов)
- Страница обратной связи

## Стек

Python, Django 5, SQLite, Pillow (обработка изображений), Bootstrap.

## Запуск

```bash
git clone https://github.com/listochek17/diplom_project.git
cd diplom_project

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/ · Админка: http://127.0.0.1:8000/admin/

## Структура

| Папка | Назначение |
|-------|-----------|
| `shop/` | настройки проекта Django, корневые маршруты |
| `shop_app/` | модели (товары, категории, корзина, избранное, комментарии), страницы магазина |
| `templates/` | общие шаблоны |

## Модели

- **Category** — категория товара
- **Article** — товар: название, описание, цена, количество, продавец, фото
- **Comment** — комментарий к товару
- **ArticleViews** — учёт просмотров товара по сессии
- **SearchHistory** — история поисковых запросов пользователя
- **Favorite** — избранные товары пользователя
- **Storage** — корзина пользователя (товар, количество)
